Vinheria Agnello

O projeto consiste no desenvolvimento de um sistema básico para cadastro de vinhos da Vinheria Agnello. A aplicação permite registrar informações como nome, tipo, safra e quantidade disponível em estoque, utilizando JavaScript para realizar a entrada e exibição dos dados.

A Vinheria Agnello é uma vinheria dedicada à comercialização de diferentes tipos de vinhos, oferecendo produtos que variam em tipo e safra. Para auxiliar na organização dos seus produtos, este projeto apresenta um sistema básico de cadastro de vinhos, permitindo registrar informações importantes como nome, tipo, safra e quantidade disponível em estoque. A proposta é utilizar a tecnologia para facilitar o controle e a organização dos vinhos da vinheria.
